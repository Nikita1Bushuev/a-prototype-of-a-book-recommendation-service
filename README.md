# Прототип книжного рекомендательного сервиса (Goodbooks-10k)

## Описание проекта
В рамках данного проекта был реализован, проанализирован и сравнен ряд подходов рекомендательных систем для сервиса по подбору книг. Работа включает в себя цикл: от разведочного анализа данных (EDA) до построения гибридной стратегии и оценки качества с помощью ранжирующих метрик.

**Датасет:** Goodbooks-10k, в работе использован сэмплированный срез.

## Структура репозитория
* `Бушуев_Никита_Рекомендательные_системы_Построение_прототипа_книжного_рекомендательного_сервиса.ipynb` — основной Jupyter Notebook с кодом, визуализациями и выводами по всем этапам.
* `README.md` — описание логики решения и результатов.

## Реализованные этапы и методы

### Этап 1. EDA 
*   **Распределение оценок:** Выявлено сильное смещение в сторону высоких оценок (66.2% оценок ≥ 4, медиана - 4.0).
*   **Активность пользователей:** Обнаружена высокая доля пользователей с малым количеством взаимодействий (25% имеют всего 2–3 оценки). Подтверждена проблема *холодного старта* для пользователей.
*   **Популярность книг:** Построена кривая Парето, демонстрирующая классический *длинный хвост*. 
*   **Теги:** Проанализированы самые частые теги. Выявлена зашумленность пользовательскими метками, что обосновывает применение TF-IDF для занижения их веса.

### Этап 2. Базовые и контентные модели
*   **Popularity (Неперсонализированная):** Рекомендация книг по среднему рейтингу.
*   **Content-Based:** Построение текстового профиля книги (название + теги), векторизация с помощью **TF-IDF** и расчет косинусного сходства. Реализована функция `get_similar_books(book_id, N=5)`.

### Этап 3. Коллаборативная фильтрация (Item-Based CF)
*   Построена разреженная матрица «пользователь-книга» (плотность ~0.18%). 
*   Для оптимизации вычислений применены **разреженные матрицы SciPy (CSR)**, центрирование оценок (вычитание среднего пользователя) и косинусное сходство. 
*   Реализована функция предсказания рейтинга на основе K-ближайших соседей.
*   *Анализ сложности:* Время \(O(U \times I^2)\), память \(O(I^2)\). Для больших данных предложены методы матричных разложений и сжатия топ-K соседей.

### Этап 4. Матричные разложения (SVD)
*   Использована библиотека **`surprise`**. Модель SVD обучена на 80% данных, протестирована на 20%.
*   **RMSE на тесте:** ~0.8466.
*   Реализована функция `get_recommendations(user_id, N=5)` для выдачи топ-N книг с наибольшим предсказанным рейтингом.

### Этап 5. Оценка и сравнение моделей
*   Оценка проводилась на 1000 случайных пользователях из тестовой выборки.
*   Релевантными считались книги с оценкой `>= 4`.
*   С нуля реализованы метрики **Precision@K, Recall@K и nDCG@K (с учетом позиции)**.
*   **Результаты:** Item-Based CF показал лучший nDCG@10 (~0.04), обогнав SVD и Popularity. Это объясняется тем, что локальные методы лучше улавливают специфичные вкусы пользователей, тогда как SVD склонен завышать оценки глобальным хитам.

### Этап 6. Гибридизация и выводы
*   Предложена **гибридная стратегия** для борьбы с холодным стартом:
    *   *Новые пользователи:* Popularity / выбор жанров при регистрации.
    *   *Новые книги:* Content-Based (TF-IDF).
    *   *Активные пользователи:* Item-Based CF или SVD (можно объединять линейной комбинацией).


*   **Выводы:** Item-Based CF — лучший по метрикам ранжирования. SVD - лучший по RMSE и масштабируемости. Content-Based решает проблему item cold-start.
*   **Пути улучшения:** Использование BERT/Word2Vec для текстов, добавление фичей пользователей и переход к нейросетевым моделям (NCF).

3. Откройте `Бушуев_Никита_Рекомендательные_системы_Построение_прототипа_книжного_рекомендательного_сервиса.ipynb` в Jupyter Notebook и запустите ячейки последовательно.
